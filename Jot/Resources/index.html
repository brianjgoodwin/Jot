Getting Started

Jot is a lightweight, focused text editor for macOS. It edits plain text and Markdown files with a clean, distraction-free interface.

Open any text file or create a new document to start writing. Use the mode selector in the bottom-right corner of the editor to switch between Plain Text and Markdown modes.

Features

Editor Modes

Plain Text

A clean editing environment with no formatting. What you type is what you get.

Markdown

Syntax highlighting for Markdown as you type. Headers, bold, italic, code, links, and more are visually distinguished in the editor.

Toggle between modes with Shift + Cmd + M or the mode selector dropdown.

Screenshot: Editor in Markdown mode

Markdown Preview

Open a live preview of your rendered Markdown in a separate window with Opt + Cmd + P.

Screenshot: Markdown preview window

Line Numbers

A line number gutter can be shown alongside the editor. Toggle it per-window with Shift + Cmd + L. The default for new windows can be set in Preferences.

Word Count

A live word count is shown in the bottom-left corner of the editor. Toggle the display with the switch next to it.

For detailed statistics, open the Word Count panel from View > Show Word Count. It shows:

  • Words, characters, and characters without spaces
  • Lines and paragraphs
  • Estimated reading time
  • File size

Word Wrap

Toggle word wrapping with Shift + Cmd + T. When off, lines extend beyond the window edge with a horizontal scrollbar.

Settings

Open Preferences with Cmd + , to configure:

  • Font -- choose any installed font and size
  • Autosave -- automatically save documents as you work
  • Line numbers -- show or hide by default in new editors
  • Remote images -- allow or block remote images in Markdown preview (off by default for privacy)

Markdown Guide

Jot supports the following Markdown syntax in both the editor (with syntax highlighting in Markdown mode) and the preview window.

Headings

Use # symbols followed by a space. The number of # symbols sets the heading level:

# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6

Bold and Italic

SyntaxResult
**bold** or __bold__bold
*italic* or _italic_italic
***bold and italic***bold and italic
~~strikethrough~~strikethrough

You can also toggle bold with Cmd + B and italic with Cmd + I in Markdown mode.

Code

Wrap inline code in single backticks: `code`

For code blocks, use triple backticks with an optional language identifier:

```javascript
console.log('Hello, world!');
```

Links

[link text](https://example.com)

Lists

Unordered lists use -, +, or * followed by a space:

- First item
- Second item
- Third item

Ordered lists use numbers followed by a period:

1. First item
2. Second item
3. Third item

Blockquotes

> This is a blockquote.
> It can span multiple lines.

Horizontal Rules

Three or more dashes, asterisks, or underscores on a line by themselves:

---

Tables

| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Cell 1   | Cell 2   | Cell 3   |
| Cell 4   | Cell 5   | Cell 6   |

Supported Files

Jot reads and writes plain-text files encoded in UTF-8.

File TypeExtensionsRole
Plain Text.txtDefault editor
Markdown.md, .markdown, .mdownEditor
Source CodeVariousViewer

You can also drag and drop supported files onto the editor window to open them.
