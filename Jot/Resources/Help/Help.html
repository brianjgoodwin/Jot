Jot - Text Editor Help

Jot - Text Editor is a lightweight text editor for macOS. It has a number of features, like syntax highlighting and previews, to make it easy to write Markdown.

It isn’t an IDE, and it isn’t a full-blown word processor. It’s more of a scratchpad. Keep it open and save code snippets, or jot down meeting notes. Oh, and it feels like an old-fashioned Mac app (if you’re into that).

Getting Started

If it’s your first time launching Jot - Text Editor, it will open with a new editor window. If you were working on a document when you quit the application, it will restore that editor window (along with any editor preferences that you set).

Jot - Text Editor is a text editor. It can open and save most plain text file formats, .txt, .md, .csv, .xml, as well as most source files (.swift, .py, etc.). It has (optional) line numbers. It comes with a number of features for working with Markdown, like Markdown preview and optional syntax highlighting.

Features Overview

Modes (syntax highlighting)

You can toggle Markdown syntax highlighting on or off either using the menu in the bottom, right of an editor window, or by pressing Shift-Command-M. In addition to syntax highlighting, Markdown mode enables Markdown Preview.

Markdown Preview

Selecting View > Markdown Preview (Option-Command-P) will open Markdown Preview. This parses your file’s content and renders it as HTML. This will update as you write (the application will wait until you stop typing to update the preview).

Jot - Text Editor displays a maximum of one Preview window. If you have have two editor windows open,both with Markdown Mode on, the Preview window will show the one in front. So if you cycle through multiple windows, the one you can edit is the one that's shown in the Preview window.

The Preview will only render editor windows in Markdown Mode. So if you wanted to work with two documents but only want one of them to ever be rendered, like a blog post draft and a reference list of links, you could toggle your links document to Plain Text mode.

You can print the Preview window, either using File > Print or Command-P. You can save as a PDF or open in Preview from the print window.

Template and Snippets

Templates are text files (.txt and .md) that you can copy to a new document. For example, meeting agendas or a blog post template. You can create a new Template by choosing File > New from Template > Create New Template..., type up your template, and save it. Templates live in a folder in the application's sandboxed container. You can view all your templates, delete some, or drag text files into this folder to add them to the menu. Anything in that folder (.txt or .md) will show in your list of templates under File > New from Template.

Snippets work similarly. You can create a new snippet by choosing Edit > Insert Snippet > Create New Snippet... and saving it. Creating a new snippet opens with placeholder text containing three variables that you can use: {{date}} today's date, {{time}} the current time, and {{cursor}} where the edit cursor will be once you've inserted your snippet. Snippets also live in a special folder, and you can access by choosing Edit > Insert Snippet > Open Snippets Folder.

Line numbers

Line numbers are off by default, you can enable them by clicking View > Show Line Numbers (Shift-Command-L) or in Settings.

Word Count

The bottom, left corner of the editor has a word count widget that updates as you type. If you want more detail, you can open View > Show Word Count to view words, characters, lines, paragraphs, reading time (estimated at 250 words a minute), and file size.

Markdown Styling Guide

Markdown is a lightweight markup language, created by John Gruber, that allows writers to write human-readable text that converts to HTML easily.

Readability, however, is emphasized above all else. A Markdown-formatted document should be publishable as-is, as plain text, without looking like it’s been marked up with tags or formatting instructions.

— John Gruber

Jot - Text Editor uses its own, custom engine for markdown syntax highlighting. It was designed to be fast, lightweight, and handle most use cases. It doesn’t support every possible edge case (it doesn’t support nested block quotes three levels deep, for example). This is what it does support:

Headers

To create headers, use the # symbol followed by a space. The number of # symbols corresponds to the header level: 

# Header 1
		## Header 2
		### Header 3
		#### Header 4
		##### Header 5
		###### Header 6

Header 1

Header 2

Header 3

Header 4

Header 5
Header 6

Bold

To make text bold, wrap it in two asterisks ** or two underscores __:

**bold text**
		__bold text__

bold text bold text

Choose Format > Bold (Command-B)

Italic

To italicize text, wrap it in one asterisk * or one underscore _:

*italic text*
		_italic text_

italic text italic text

Choose Format > Italic (Command-I)

For bold and italic at once, use three asterisks: bold italic text.

Strikethrough

To strikethrough text, wrap it in two tildes ~~:

~~strikethrough text~~

strikethrough text

Choose Format > Strikethrough

Code

For inline code, wrap the text in backticks `, or use Format > Strikethrough:

Here's some `inline code`

Here's some inline code

For code blocks, wrap the text in triple backticks ``` with an optional language identifier: 

console.log('Hello, world!');

Blockquotes

For block quotes, start a line with an angle bracket > or choose Format > Blockquote:

> This is a block quote

This is a block quote

You can split the quote with multiple angle brackets, if visual spacing is important to you. It will still render as a single block quote. 

> This is 
		  > also a 
		  > block quote

This is also a block quote

Links

To create a link, wrap the link text in square brackets [] and put the URL in parentheses ():

[link text](https://example.com)

link text

In Markdown Mode, you can also select some text and paste a copied URL over it: the selection becomes the link text. To replace the selection with the URL instead, use Edit > Paste and Match Style (Option-Shift-Command-V).

Lists

For unordered lists, use -, +, or * followed by a space:

- Item 1
		- Item 2
	  - Item 3
  • Item 1
  • Item 2
  • Item 3

For ordered lists, use numbers followed by a period and a space:

1. Item 1
	  2. Item 2
	  3. Item 3
  1. Item 1
  2. Item 2
  3. Item 3

In Markdown Mode, pressing Return inside a list item starts the next item automatically (numbered lists count up as you go). Press Return on an empty item to end the list. Jot doesn’t renumber the rest of a numbered list when you insert an item in the middle — adjust the following numbers by hand.

Tab and Shift-Tab indent and outdent the current line or selection, so nested lists continue at the right depth.

Checklists

For task lists, use a bullet followed by brackets:

- [ ] An open task
	- [x] A completed task
  • [ ] An open task
  • [x] A completed task

Completed tasks appear crossed out in Markdown Mode. Use Format > Toggle Checklist (Command-L) to check or uncheck the current line or every selected line. On lines that have no checkbox yet, the same command adds one — plain lines and bullet items become open tasks.

Tables

For tables, separate columns with pipes | and put a separator row under the header:

| Name  | Notes    |
	|-------|----------|
	| lorem | ipsum    |
	| dolor | sit amet |
Name Notes
lorem ipsum
dolor sit amet

In Markdown Mode, the header row is bolded and the pipes are dimmed. The columns don’t have to line up — the separator row is what makes it a table.

Horizontal Rules

For a horizontal rule, put three or more hyphens, asterisks, or underscores on a line by themselves:

---
